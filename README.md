# Adonai RH — Institutional Website

Institutional website for **Adonai RH**, an HR consulting firm in Campinas, Brazil, offering recruitment, internship placement and HR consulting services.

![Homepage](home.png)

## ✨ Highlights

- 📱 **Responsive** layout for mobile, tablet and desktop
- 🌗 **Dark mode** support
- 🎞️ **Client logo carousel** built with Swiper
- ✨ **Scroll-triggered fade-in animations**
- 🔎 **SEO basics** — meta description, favicon and semantic HTML (`lang="pt-BR"`)

## 🧰 Tech stack

- HTML5
- [Tailwind CSS](https://tailwindcss.com/) v4 (compiled with the Tailwind CLI)
- JavaScript
- [Swiper](https://swiperjs.com/) — carousel
- [Font Awesome](https://fontawesome.com/) — icons

## 🚀 Running locally

```bash
git clone https://github.com/whoistavs/site-adonair.git
cd site-adonair
npm install
npm run build-css    # compiles input.css → style.css
```

Then open `index.html` in your browser.

To recompile CSS automatically while editing:

```bash
npm run watch-css
```
